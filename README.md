# Hey, Nyasha and Noga!

As of March 5th, this is the bare bones for a our app. It's generated from the standard SvelteKit template, with the addition of the `manifest.json` file that's needed to make the app installable.

Just boot up the app, go to the website and install the app.

## how to start the project

1. Make sure you have [Node.js](https://nodejs.org/en) installed on your system.
   - or alternatively just create a github codespace
2. Open your terminal and run the following commands.

```shell
npm install
npm run dev
```

Or you can be cool like me and use yarn instead of npm.

3. go to the link printed in your terminal. it should be `http://localhost:5173`
